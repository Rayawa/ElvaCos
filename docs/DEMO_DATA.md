## 维护与验证

`python3 scripts/generate_demo_data.py` 从 `sources.json` 重新生成 `dataset.json`，不联网、不操作设备。修改后用 `./scripts/build.sh` 构建。

`./scripts/demo-test.sh` 在已连接设备上运行 5 个 Hypium 用例：已有数据时跳过自动填充、追加与备份兼容、离线媒体读取及清理、重复加载保留编辑与删除、清空后自动跳过并允许手动重建。使用独立 `verification-demo-*.db` 和隔离媒体目录，测试不访问用户 `personal.db`。

本次验证：默认 HAP 与 ohosTest HAP 构建通过；2026-10-08 已连接设备上 Hypium 5/5 Pass，Failure 0、Error 0；现有 SQLite 模型回归 12/12 通过。主应用启动后确认自动填充成功，首页可显示计划、活动、任务和花费总额。
