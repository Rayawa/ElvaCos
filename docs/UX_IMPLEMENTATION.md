## A（2026-10-08）

- `PlanReadiness` 在 AppState 的 `@Computed` 中派生；首页待办来源、计划卡和详情的准备/装备/打包/花费摘要共享模型对象。等待字段的持久化与交互在 D 落地，当前只提供聚合规则。
- 操作结果提供 `ok / partial / failed / savedNotRefreshed`；旧布尔调用只表达是否已提交。写入成功而刷新失败时显示持续的重新加载入口，禁止对旧快照继续写入；重新加载只读数据，不重放新增。常规写入按依赖集合刷新，并在相关读取全部成功后发布快照。写入仍串行；触觉反馈不阻塞保存结果。
- 新增 schema v4 的可空预算标记；历史正数标为已设置，历史零保留未知。新表单留空为未设置，显式填 0 为零预算；编辑其他字段保留旧未知标记。
- 元数据备份 v4 保留预算三种语义，兼容 v1/v2/v3；所有验证在内存 SQLite 中进行，未操作用户 personal.db。
- 成片统一为 FINAL/PUBLISHED，RETOUCHED 单列已修；相册、作品集、统计与模型共享映射。更新受影响的原有断言。
- 导入取消安静返回；成功、跳过重复、失败分别表达，全部失败不显示成功；常用打包项生成改为单事务。

## B（2026-10-08）

- schema / 元数据备份升至 v5，新增 `entries`、类型与归属约束、索引；对象删除时其收录自动回到未归位。旧 v1–v4 备份仍可替换恢复；当前收录在旧备份替换时清空，符合完整替换语义。
- 首页提供「收录一条」与仅非空时显示的未归位数量；收录箱支持未归位/全部、类型筛选、置顶、图片原图、链接打开、修改和删除。捕获不用填写标题、分类或归属；文本与链接自动判断，图片由系统 Picker 选一张后保存。
- 收录箱中已归位条目只跳转归属对象，归属对象的收录视图承担编辑。活动/计划/角色/装备都有摘要入口；当前通过带 scope 的收录目的地访问，最终用同一 `EntryCollection` 集成进 C/D/F 的对象分段。没有新增 Tab。
- 归位为可选第二步；支持转为准备任务、花费或参考图。新对象写入与源收录删除在同一事务中完成；失败保留源条目；参考图转换保留媒体，不进入成果照片计数。收录修改在关闭按钮、返回与拖动关闭时保护未保存输入。
- 收录图片纳入媒体维护的保留集合；恢复只复用本机可信的既有收录 ID 对应图片，不接受导入文件给出的外部路径。缺失图片可在既有条目上重新选图。
- 粘贴采用原生 `PasteButton` 的临时授权，再调用 pasteboard 的 `getData / getPrimaryText`，没有新增常驻剪贴板权限；本机 SDK API 26 的声明确认 PasteButton 自 API 10、授权回调自 API 18 可用，符合最低 API 23。尝试查阅华为官方粘贴组件/API 文档，但网页超时或只返回导航，未取得可读正文；未宣称实际设备粘贴授权已验证。

验证：`./scripts/build.sh` 无签名主包构建通过；`python3 scripts/test_schema.py` 15/15；DevEco Node 执行 `scripts/test_ux_models.cjs` 21/21。新增证据覆盖无必填元数据捕获、非法归属、对象删除归回收录箱、任务/花费/参考图转换与失败回滚、v4 备份兼容、收录媒体路径清理。未运行设备套件，系统 Picker、粘贴组件、链接打开与页面触控路径仍缺少真机证据。
