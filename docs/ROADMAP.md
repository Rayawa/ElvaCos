# 当前能力与后续方向

版本基线：**1.0.0-beta.1（10000001）**；文档核对：2026-10-08。现状与历史证据；最终构建、签名与交付结论见 [打包记录](RELEASE.md)。

本文帮助了解已有能力和可继续处理的问题，不是固定优先级、执行计划或强制验收清单。后续范围、实现方式和验证投入以用户当次任务为准；历史过程与报告保存在 VALIDATION。

## 当前已具备

- 角色/版本、Cos 计划、衣柜、活动、打包、照片与作品的离线管理。
- 分类准备模板和自定义任务、独立准备进度、参考图、本机团队分工、逐笔花费与分类统计。
- 待定/单日/多日活动、时间段、月历、可选系统提醒和设备日历确认页。
- 加密 RDB v3、增量迁移、事务保护、元数据备份 v3 与旧格式兼容、沙箱媒体管理及系统备份注册。
- Dashboard 参考结构：ability/common/component/pages/main|detail|more，保留 model/data；应用公共状态入口与 AppStorageV2，Preferences / StorageLink 设置。
- 五个 HDS 导航 Tab、覆盖详情、业务动作栏、表单/关联 Sheet；公共图标、浅深色资源、按压/触觉/入场工具。
- 实际容器宽高适配、短横屏单列、详情宽度上限、响应式照片网格、分类金额条形图与筛选。
- 更新日志及 Beta/RC/正式版独立筛选；原生隐私正文阅读，单一来源 privacy.html。
- 分阶段启动、销毁等待操作及数据库关闭、Timer/握姿/异步回写取消守卫；中文无障碍标签。设置与主页 Tab 每次进入应用仅首次入场，原生设置列表不叠加按压特效。
- 五组浅深配色、独立外观偏好，Canvas 月度花费趋势与照片处理分布。
- 原神与绝区零离线示例；Debug 首次空库自动加载，Release 手动追加。
- 当前版本 1.0.0-beta.1，构建号 10000001；Release HAP / APP 与 SHA-256 交付清单已生成。

## 已知问题与验证边界

- 华为账号已配置用户提供的 Client ID；已记录的真机登录返回 1001502003，需要核对 AGC 与签名 Profile。云数据与照片同步尚未实现。详情见 HUAWEI_ACCOUNT_SETUP。
- 提供的 privacy.html 中云端服务、账号注销与撤回同意描述与当前离线能力存在差异。阅读页忠实读取原文；目前没有 Dashboard 的同意/撤销流程，后续可根据产品实际能力处理。
- API 26 手机已取得原生业务与隔离布局证据；API 23、真实 Tablet/2in1/折叠、多窗安全区、系统字号和读屏人工体验尚未覆盖。
- 系统日历确认页取消路径已验证；真实保存后的后台提醒投递、跨设备日历同步仍无完整证据。
- HDR、触觉、握姿、近场能力的自动化检查不等同于实际硬件观感；当前核心数据功能可独立使用。
- 历史重构收尾时设备曾断开；本次重新连接设备并对最终包进行回归，以 RELEASE / VALIDATION 的最新记录为准。
- 当前 Release 编译包使用开发调试 Profile；市场发行需要发行证书/Profile。旧账号文档的根证书指纹已更正为应用开发证书指纹，AGC 登录仍需复核。
- 内置官方角色图片的公开来源不等于取得发行授权，对外发布需要维护者明确使用范围。

这些边界说明已有证据，不阻止继续处理结构、性能、缺失功能和 bug，也不要求每次任务跑完所有设备检查。
