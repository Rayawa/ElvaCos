## 维护约定

先变更领域模型/迁移，再改 Repository，再改 UI。新数据列通过增量迁移引入。硬件能力集中适配并附官方 API 依据。每次垂直切片必须构建；涉及关系/迁移/清理的修改补充真正验证业务约束的测试。品牌仅修改 AppScope/资源。所有未实现能力以此文件跟踪，不创建假入口。
