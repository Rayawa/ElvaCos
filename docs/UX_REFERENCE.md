## 最值得学习的内容

### 一次计划包含用户实际关心的准备事项

视频的新建入口将角色资料和准备计划放在一起。用户从「想出谁」直接进入「如何准备」，无需先理解两个独立的数据实体。

默认准备清单有明确的 Coser 语境：

| 分类 | 画面中的默认任务 |
|---|---|
| 假发 | 购买、收货、造型 |
| 服装 | 购买、收货、试穿 |
| 美瞳 | 购买、收货 |
| 化妆 | 妆容 |
| 拍摄 | 预约摄影 |
| 制作 | 预约后期 |

每组都有添加任务入口，整个清单还有添加新分类入口。这里管理的是准备工作的完成情况，与衣柜资产的所有权、可用状态、当天是否已经装包是不同的事情。

团队成员默认分工为毛娘、妆娘、摄影、后勤、后期。计划同时容纳角色形象图片与额外参考图片，体现准备阶段对视觉资料的需要。

### 用户可以先记录不完整的计划

角色计划提供截止日期开关；活动提供「待定 / 具体日期 / 跨越多天」和「不标记时间 / 标记开始时间 / 标记时间段」。页面承认用户可能尚未确定时间，后续浏览也为日期待定的活动保留分组。

本工程现在要求漫展具有单个有效日期，目标日期需要手输 YYYY-MM-DD。待定、多天和时间段不能只靠改页面实现，需领域模型、增量迁移和相关测试。

### 入口与内容位于同一语境

首页明确提供新计划、新活动；空卡片允许直接添加。列表右上角有加号，各清单分组内可以就地添加任务。内容分组与操作位置对应，减少用户寻找入口的成本。

计划列表以进行中、已完成、待定等用户关心的状态组织。活动支持列表与日历两种查看方式；同一份数据服务不同的查找需求。

## 对 ElvaCos 的具体设计建议

以下是根据视频与当前代码提出的设计方向，不是视频中已验证的行为。

1. 对用户使用「新建 Cos 计划」作为连续入口。在流程内选择已有角色或填写新角色，保存时仍保留 Character 与 CosProject 的内部关系。新角色与项目应通过同一事务保存，避免留下半完成记录。
2. 新建先收集角色/计划名称等最少信息；准备模板、日期、参考图、团队等信息允许逐步补充。模板可选择和删改，已有装备不应强制生成购买任务。
3. 项目提供准备、打包、照片三种任务视图。准备按假发、服装、妆造、拍摄等分组；打包显示携带物与存放位置；照片展示拍摄成果。准备完成和打包确认分别保存。
4. 首页优先显示正在准备的计划、最近日期及下一项未完成任务。主动作继续使用 HDS 原生标题动作/toolbar；空状态只提供对应的启动入口，避免在有数据的页面重复堆放同一主动作。
5. 角色形象图片与参考图可在准备阶段添加，无需先导入成果照片再设角色封面。媒体继续由 MediaRepository 管理，使用系统 Picker 处理用户明确选择的图片。
6. Cos 默认展示计划，以进行中、已完成、全部等筛选帮助查找；角色资料作为可复用资料。与视频的角色计划合并呈现方式相比，本工程仍需表达同角色多版本、多次计划。
7. 活动可覆盖漫展、外景拍摄、约拍等日程。先明确事件类型、日期语义和兼容既有漫展数据的方案，再扩展列表/日历和可选提醒。
8. 团队分工、实际花费属于后续领域扩展。当前预计预算和关联资产价格之和不能直接称为本次计划实际花费；复用衣柜装备不等于产生新的支出。

## 视觉与交互取舍

可复用的设计是清晰的分组标题、具体的动作名称、带示例的输入、图片占位入口、分组任务和状态筛选。颜色、图标、材质、反馈、导航继续遵循 UI_STYLE.md 和 Dashboard 复用约定，保留五个独立 HDS 导航 Tab。

参考视频也存在需要改善的地方：

- 新建计划表单很长；基本信息之后的准备模板、团队和参考资料适合逐步展开或保存后完善。
- 顶部保存与底部创建表达同一提交动作，容易混淆；应选择一致的提交方式。
- 首页品牌横幅和巨大空卡占用首屏较多空间；有数据时应优先呈现计划及下一步。
- 「角色」「角色计划」「新计划」的称呼存在交叉；本工程应明确角色资料与一次计划的区别。
- 多个空分组可以合并为有行动入口的整体空状态。
- 提醒开关、日历和预算页面的存在，不足以证明对应完整流程已经可用。

## 建议实施顺序与验收方向

第一批：连续新建计划、可编辑的准备模板、准备与打包分离、项目就地添加装备/任务。领域变化必须采用递增迁移并保留已有清单含义；不得把用户既有打包确认自动解释成准备任务完成。

第二批：准备阶段图片、计划状态筛选、围绕近期计划的首页。

后续：团队分工、活动日期扩展及日历、实际花费记录、提醒。未实现前不创建假入口。

后续验收以真实任务为单位：首次用户从新计划入口连续完成创建；已有角色/装备可以复用且不重复购买；假发造型可独立于资产可用状态记录；勾选准备任务不影响打包确认；取消或保存失败不留下半份计划；旧数据与照片保持完整。
